# Background Model for Peak-Based Loop Calling

To distinguish biologically significant chromatin loops from spurious ligation artifacts in peak-based sequencing data, Chr3D implements a **peak-anchored empirical background model** applicable to both ChIA-PET and HiChIP.

The model evaluates each candidate P2P (peak-to-peak) interaction against a Negative Binomial null distribution derived from 10,000 distance-matched random placements in non-peak genomic regions, with significance assessed via Benjamini–Hochberg (BH) FDR correction.

---

## Step 1: PET Classification

After obtaining broad peaks from MACS3, all PETs are classified into three categories based on whether their anchors overlap called peak regions:

| Category | Description |
|----------|-------------|
| **P2P** (peak-to-peak) | Both anchors fall within peak regions — candidate loop interactions |
| **D2D** (distal-to-distal) | Both anchors fall outside peaks — used as background reference |
| **P2D** (peak-to-distal) | One anchor in a peak, the other outside |

**Implementation details:**
- Overlap detection is performed in a fully vectorised manner using NumPy broadcast operations partitioned across chromosomes, enabling classification of tens of millions of PETs in parallel without per-row iteration.
- Centromeric and telomeric regions are excluded from peak overlap consideration by masking UCSC cytoband annotations with a ±5 Mb buffer around acrocentric bands, preventing artifactual classification driven by repeat-dense genomic regions.

```bash
--standard-chroms    # restrict to chr1-22 + chrX/Y
--cytoband FILE      # UCSC cytoband BED for centromere masking
```

---

## Step 2: Template Extraction

P2P PETs are used to define interaction **templates**. Each unique peak pair is encoded as a template parameterised by three geometric quantities:

| Variable | Formula | Description |
|----------|---------|-------------|
| `w1` | `peak1_end − peak1_start` | Width of left anchor |
| `w2` | `peak2_end − peak2_start` | Width of right anchor |
| `d` | `peak2_start − peak1_end` | Distance between anchors |

**Constraints:**
- Templates restricted to **cis-chromosomal** pairs to ensure the distance-dependent decay model remains valid
- Same-peak PETs excluded to avoid self-ligation artifacts
- Canonical pair keys generated by sorting peak indices (`key1 < key2`) to ensure symmetric counting regardless of read-pair orientation

---

## Step 3: Empirical Background Estimation

For each template, a background null distribution is estimated by performing **N = 10,000 random placements** of an identically-shaped genomic window across non-peak D2D regions of the same chromosome.

For each random placement *k*, the background count is defined as the number of D2D PETs whose both anchors fall within the randomly placed window simultaneously.

**Computational efficiency:**
- All 10,000 random start positions are generated simultaneously using vectorised NumPy sampling
- D2D midpoint lookups accelerated via `np.searchsorted` on pre-sorted chromosome-partitioned arrays
- Achieves **O(N log M)** complexity per template, where M is the number of D2D PETs on the chromosome

---

## Step 4: Negative Binomial Parameter Estimation

The empirical count vector from the 10,000 random placements is used to fit a **Negative Binomial (NB) distribution** via method-of-moments estimation.

The NB model is appropriate because proximity-ligation contact counts exhibit **overdispersion** relative to the Poisson expectation — a consequence of stochastic chromatin looping dynamics and amplification noise (variance > mean).

The dispersion parameter *r* and success probability *p* are estimated from the empirical mean and variance:

```
μ = mean(background_counts)
σ² = var(background_counts)

r = μ² / (σ² − μ)
p = μ / σ²
```

<Callout type="warning">
  When σ² ≤ μ (underdispersion), the model falls back to a Poisson approximation to avoid numerical instability.
</Callout>

---

## Step 5: Significance Testing and FDR Control

The observed P2P PET count for each template is tested against its fitted NB null distribution to obtain a one-sided p-value. Multiple testing is controlled using **Benjamini–Hochberg FDR correction** at α = 0.05 (configurable via `--alpha`).

Templates passing the FDR threshold are written to `significant_loops.csv`.

**Output columns:**

| Column | Description |
|--------|-------------|
| `chrom1`, `start1`, `end1` | Left anchor coordinates |
| `chrom2`, `start2`, `end2` | Right anchor coordinates |
| `pet_count` | Observed P2P PET count |
| `bg_mean` | Background mean count |
| `p_value` | Raw NB p-value |
| `q_value` | BH-adjusted FDR q-value |
