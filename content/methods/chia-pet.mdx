# ChIA-PET Pipeline

ChIA-PET (Chromatin Interaction Analysis by Paired-End Tag sequencing) is a **peak-based** technique that enriches for chromatin interactions mediated by a specific protein factor. The Chr3D ChIA-PET pipeline processes raw paired-end FASTQ files through four sequential stages.

```bash
chr3d chia-pet \
    --r1 sample_R1.fastq.gz \
    --r2 sample_R2.fastq.gz \
    --genome hg38.fa \
    --linkers ACGCGATATCGCG \
    --output-dir ./results \
    --sample-id ctcf_gm12878
```

---

## Pipeline Overview

<Steps>

### Linker Filtering

In the original ChIA-PET protocol, paired-end tags (PETs) were generated by ligating interacting chromatin fragments with two separate half-linker sequences. Long Read ChIA-PET further standardised the use of a single bridge linker combined with Tn5 transposase tagmentation, producing read pairs of up to 200 bp.

Chr3D's linker filtering module bypasses legacy half-linker logic and directly identifies the bridge linker within each read using **Smith–Waterman local alignment** via the [parasail](https://github.com/jeffdaily/parasail) SIMD library (AVX2/SSE4.1/AVX512).

To fully exploit available CPU resources, input paired FASTQ files are partitioned into balanced chunks and dispatched in parallel across all available cores. Each worker independently performs:
- Linker detection
- Tag extraction
- Categorical classification of PETs (same-linker AA/BB and single-read AX/XA categories following ChIA-PET Tool V3 notation)

Per-chunk outputs are merged into final FASTQ files, substantially reducing end-to-end linker filtering time.

**Key parameters:**

| Parameter | Default | Description |
|-----------|---------|-------------|
| `--linkers` | required | Comma-separated bridge linker sequence(s) |
| `--min-score` | `20` | Minimum parasail alignment score |
| `--min-tag` | `15` | Minimum genomic tag length after linker removal (bp) |
| `--max-tag` | `40` | Maximum genomic tag length after linker removal (bp) |

### Mapping

Linker-filtered genomic tags are aligned to a reference genome using **BWA**:

- Tags **< 55 bp** → `BWA-ALN SAMPE` (superior sensitivity for short reads)
- Tags **≥ 55 bp** → `BWA-MEM` (multi-threaded, reduced runtime)

Following alignment, mapping quality statistics are assessed via `samtools flagstat`, and reads are filtered to a minimum MAPQ of 30 to retain uniquely mappable pairs. Accepted read pairs are converted to **BEDPE** format using 5′ anchor coordinates and deduplicated by exact position to remove PCR amplification artifacts prior to downstream PET classification.

**Key parameters:**

| Parameter | Default | Description |
|-----------|---------|-------------|
| `--mapq` | `30` | Minimum mapping quality |
| `--threads` | `4` | CPU threads for BWA / samtools |

### Peak Calling

Enriched anchor regions are identified using **MACS3 broad peak calling**, reflecting the protein-factor binding sites that define the interaction anchors characteristic of ChIA-PET data.

**Key parameters:**

| Parameter | Default | Description |
|-----------|---------|-------------|
| `--genome-size` | `hs` | MACS3 genome size (`hs`, `mm`, or integer) |
| `--qvalue` | `0.05` | MACS3 q-value cutoff |

### Background Model & Loop Calling

After peak calling, PETs are classified and evaluated against an empirical null distribution to identify significant loops. See [Background Model](/methods/background-model) for full details.

Steps within this stage:
1. **PET classification** — P2P, D2D, P2D categorisation
2. **Template extraction** — unique peak-pair templates parameterised by anchor widths and distance
3. **Empirical background estimation** — 10,000 random D2D placements per template
4. **Negative Binomial fitting** — method-of-moments parameter estimation
5. **FDR correction** — Benjamini–Hochberg at α = 0.05

**Key parameters:**

| Parameter | Default | Description |
|-----------|---------|-------------|
| `--alpha` | `0.05` | FDR significance threshold |
| `--standard-chroms` | off | Restrict to chr1–22 + chrX/Y |
| `--cytoband` | — | UCSC cytoband file for centromere exclusion |

</Steps>

## Output Layout

```
<output-dir>/
├── linker_filtered/     filtered FASTQ files (same-linker PETs)
├── mapped/              BAM + deduplicated BEDPE
├── peaks/               MACS3 broadPeak files
├── loops/               significant_loops.csv
└── qc/                  pipeline summary report
```

---

## Resuming a Run

```bash
chr3d chia-pet --start-from 3 ...   # resume from peak calling
```

| Step | Description |
|------|-------------|
| 1 | Linker filtering |
| 2 | Mapping |
| 3 | Peak calling |
| 4 | Background model / loop calling |

<Callout type="info">
  When resuming, outputs from prior steps must exist at canonical paths under `--output-dir`.
</Callout>
