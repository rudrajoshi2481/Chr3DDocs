# Single-Nucleus Hi-C Module (`chr3d.hic`)

Processes single-nucleus Hi-C data from multiple cells. Each cell is processed independently through the standard Hi-C steps, followed by QC filtering, pseudobulk aggregation, and optional clustering.

<Callout type="info">
The `SnHiCPipeline` reuses bulk Hi-C components (`HiCAligner`, `HiCSamProcessor`, `HiCPairsProcessor`, `HiCMatrixGenerator`) and applies them per-cell.
</Callout>

## Overview

The single-nucleus Hi-C module provides a complete pipeline for processing individual cell Hi-C data, including per-cell processing, quality control, pseudobulk aggregation, and optional clustering.
