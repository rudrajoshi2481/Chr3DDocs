# Bulk Hi-C Module (`chr3d.hic`)

Complete Hi-C processing pipeline for bulk (population-level) chromatin interaction data.

<Callout type="info">
All classes in this module can be imported either from `chr3d` directly or from `chr3d.hic`.
</Callout>

## Overview

The bulk Hi-C module provides a complete pipeline for processing population-level Hi-C data, from raw FASTQ files to contact matrices and downstream analysis.

## Components

### Pipeline Orchestrator
- [HiCPipeline](hic/HiCPipeline) - Complete Hi-C pipeline orchestrator

### Individual Processing Steps
- [HiCAligner](hic/HiCAligner) - BWA MEM alignment for Hi-C data
- [HiCSamProcessor](hic/HiCSamProcessor) - SAM/BAM processing with samtools
- [HiCPairsProcessor](hic/HiCPairsProcessor) - Pairtools for pairs processing
- [HiCMatrixGenerator](hic/HiCMatrixGenerator) - Cooler for contact matrix generation

### Utilities
- [HiCQCAnalyzer](hic/HiCQCAnalyzer) - Quality control analyzer
- [FastqSplitter](hic/FastqSplitter) - Split FASTQ files for parallel processing
